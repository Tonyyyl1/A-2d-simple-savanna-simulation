# Savanna Simulation v2.7-r2-e02-preview

[English](README.md)

**开发预览**

包含持续追逐目标和真实接触捕食，仍处于 R2-E02 开发阶段。

项目从 David J. Barnes 和 Michael Kölling 的 BlueJ 狐狸与兔子示例扩展而来，模拟五种动物的捕食、放牧、疾病与天气。

## 使用 Java 17 或以上版本

```sh
java -jar savanna-simulation-v2.7-r2-e02-preview.jar
```

## 从源码启动

```sh
BUILD_ID=local-dev ./build.sh
./run.sh
```
